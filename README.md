# RO’Lyfe Acquisition Engine

A real estate deal acquisition and analysis platform built for speed, automation, and investor decision-making.

## Flow

Lead → Analyze → Offer → Contract → Funding → Close

## Shared Property Research Dock

This project loads the shared RO’Lyfe Property Research Dock for a consistent route into map-led research, listings/comps, tax-sale and auction portals, parcel and official public records, flood-risk tools, capital routes, and closing documents. It opens sources/searches and does not scrape or claim to import verified live data.

Shared workflow standard: https://github.com/ROLRichman/rolyfe-property-research-intelligence/blob/main/PROPERTY_RESEARCH_STANDARD.md
Shared component: https://github.com/ROLRichman/rolyfe-property-research-intelligence/blob/main/shared/property-research-dock.js
